# Plantilla: desglose de subtareas

## Prompt

Necesito dividir esta tarea en subtareas concretas y secuenciadas:
- Tarea principal: [título]
- Descripción: [detalle]
- Estado actual: [pendiente / en progreso]
- Dependencias conocidas: [si/no + detalle]

Genera una lista de subtareas con este formato:
- `Título`
- `Descripción breve`
- `Definición de terminado`
- `Dependencias`
- `Prioridad` (alta/media/baja)

Además:
- Marca qué subtareas pueden ejecutarse en paralelo.
- Señala el primer paso recomendado para empezar hoy.

## Resultado esperado

Checklist operativo para ejecución diaria.
