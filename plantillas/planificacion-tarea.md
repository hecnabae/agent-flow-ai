# Plantilla: planificación de tarea

## Prompt

Actúa como copiloto de productividad técnica.

Quiero planificar esta tarea:
- Contexto: [describe el problema o necesidad]
- Resultado esperado: [qué debe quedar listo]
- Restricciones: [tiempo, dependencias, stack, políticas]
- Fecha objetivo: [fecha]

Entrégame:
1. Objetivo en una sola frase.
2. Alcance (incluye / excluye).
3. Criterios de aceptación verificables.
4. Riesgos y mitigaciones.
5. Estimación inicial (S/M/L) con justificación breve.

## Resultado esperado

Una definición de tarea lista para registrarse en el sistema.
