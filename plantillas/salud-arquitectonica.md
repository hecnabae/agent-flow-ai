# Plantilla: salud arquitectónica

## Prompt

Actúa como arquitecto de software y evalúa la salud del sistema.

Contexto:
- Componente o servicio: [nombre]
- Síntomas actuales: [fallas, lentitud, complejidad]
- Cambios recientes: [resumen]
- Restricciones del negocio: [detalle]

Entrega:
1. Diagnóstico de riesgos arquitectónicos.
2. Deuda técnica priorizada (alta/media/baja) con impacto.
3. Recomendaciones en dos horizontes:
   - Quick wins (1-2 semanas)
   - Mejoras estructurales (1-3 meses)
4. Métricas para monitorear si las mejoras funcionan.

## Resultado esperado

Plan de mejora técnica accionable y priorizado.
