# Plantillas de prompts

Este directorio reúne plantillas reutilizables para los prompts más comunes en Agent Flow AI.

## Contenido

- `planificacion-tarea.md`: para convertir una idea en una tarea clara con alcance y criterios de éxito.
- `desglose-subtareas.md`: para descomponer una tarea en subtareas accionables.
- `priorizacion-foco.md`: para ordenar trabajo según impacto, urgencia y energía disponible.
- `revision-progreso.md`: para revisar avances, bloqueos y siguientes pasos.
- `salud-arquitectonica.md`: para evaluar deuda técnica y proponer mejoras.

Puedes copiar la plantilla, completar los campos entre corchetes y usarla directamente en tu flujo de trabajo.
