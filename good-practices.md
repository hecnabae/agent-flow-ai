# Good Practices de Prompting

Este documento recopila prácticas recomendadas para redactar prompts de alta calidad en flujos de trabajo con IA.

## Temas

1. **Especificidad y restricciones claras**  
   Define el alcance, los límites y el formato de salida esperado para reducir ambigüedad.

2. **Prompts con estructura: Contexto + Objetivo + Verificación**  
   Usa una estructura explícita para guiar el razonamiento y facilitar respuestas útiles y auditables.  
   ➜ Ver guía completa: [Tema 2: Contexto + Objetivo + Verificación](./tema-2-prompts-estructurados.md)

3. **Iteración y refinamiento continuo**  
   Mejora el prompt por ciclos cortos, incorporando feedback sobre fallos concretos.
