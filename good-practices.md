# Good Practices para crear prompts eficaces

Este documento reúne una guía práctica para diseñar prompts de alta calidad. Está organizado por temas para poder profundizar en cada técnica sin perder una visión global.

## Índice de temas

1. **Definir alcance y restricciones**
2. **Prompts con estructura: Contexto + Objetivo + Verificación**
3. **Iteración y mejora continua del prompt**

## Flujo recomendado (paso a paso)

1. **Entender el problema real**
   * Identifica qué decisión o resultado necesitas.
   * Distingue entre información crítica y ruido.
2. **Aportar contexto relevante**
   * Incluye dominio, audiencia, formato esperado y límites.
   * Evita contextos ambiguos o contradictorios.
3. **Definir un objetivo claro y medible**
   * Formula el objetivo en términos de salida observable.
   * Especifica tono, longitud, idioma y nivel de detalle.
4. **Solicitar verificación explícita**
   * Pide criterios de calidad, checklist o autoevaluación.
   * Añade validaciones sobre cobertura, precisión y formato.
5. **Iterar por versiones**
   * Revisa la salida con criterios concretos.
   * Ajusta el prompt en ciclos cortos (v1, v2, v3).
