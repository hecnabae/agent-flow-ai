# Good Practices de desarrollo

Este documento recoge una guía práctica para trabajar de forma segura, incremental y con feedback rápido.

## Flujo recomendado (resumen)

1. **Entender el objetivo y el contexto**: confirmar alcance, criterio de aceptación y restricciones.
2. **Planificar en pasos pequeños**: dividir el trabajo en tareas verificables.
3. **Aplicar cambio mínimo viable**: modificar lo justo para avanzar sin introducir ruido.
4. **Ejecutar el bucle obligatorio**: **plan → cambio mínimo → test → fix** hasta que el objetivo quede cumplido.

## Reglas de calidad

- Mantener los cambios atómicos y fáciles de revisar.
- Priorizar legibilidad y consistencia con el estilo existente.
- Validar siempre con pruebas o checks reproducibles.
- Documentar decisiones y límites conocidos.
