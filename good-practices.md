## Tema 3 · Evita el “prompt spaghetti” con documentos de control

Cuando un proyecto crece, las instrucciones repartidas en mensajes sueltos se vuelven difíciles de seguir: aparecen contradicciones, duplicidades y decisiones no documentadas. Para evitarlo, utiliza un documento de control centralizado.

### Pasos recomendados

1. **Centraliza el contexto base** en un documento único (objetivo, alcance, convenciones y límites).
2. **Separa reglas estables de decisiones temporales** para no mezclar política con ejecución diaria.
3. **Versiona cambios relevantes** (qué cambió, por qué y cuándo).
4. **Define plantilla de trabajo por tarea** con secciones fijas: entrada, proceso, validación, salida.
5. **Establece checklist de calidad** previo al cierre de cada entrega.
6. **Conecta artefactos entre sí** mediante enlaces explícitos (brief ↔ plan ↔ resultados).
7. **Haz revisión de coherencia periódica** para eliminar reglas obsoletas y consolidar duplicados.
